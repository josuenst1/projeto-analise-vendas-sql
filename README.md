 Projeto: Análise de Desempenho de Vendas (SQL + Python)
Criei este repositório para organizar meus estudos práticos de banco de dados e automação. A ideia foi simular um cenário real de uma empresa que precisa extrair valor dos seus dados de vendas.

 Objetivo do Projeto
Muitas vezes os dados estão brutos e não geram conhecimento para a empresa. Usei SQL para estruturar o banco do zero e criar consultas que respondem perguntas de negócio, como identificar os clientes mais fiéis e os produtos com maior faturamento.

 O que desenvolvi aqui:
Modelagem de Dados: Estruturei as tabelas e relacionamentos focando na integridade das informações.

Consultas Analíticas: No script de análises foquei em gerar métricas reais de desempenho e rankings.

Integração com Python: Desenvolvi um script para automatizar processos que seriam manuais, unindo o poder do Python com o banco de dados.

 Estrutura dos Arquivos
1-ESTRUTURA.sql: Criação das tabelas e chaves

2-DADOS.sql: Inserção de dados para teste das consultas

3-ANALISES.sql: Onde executei as queries para extração dos resultados de vendas

4- Automação.py: Script Python integrando a solução
